# Store editor – home page, pages, theme, menus, policies

Everything here is under **Online store** in the `/cms` sidebar.

---

## 1. Edit the home page

1. **Online store → Home page & pages** → open the page whose handle is **`home`**.
2. The page is built from **Sections** (blocks). Each section is one strip of the page:
   - **Store**: Hero slider, Trust badges, Category grid, Parts finder, Brand strip, Installment banner, Testimonials, Instagram & TikTok, Store location & map
   - **Products**: Hot deals, Product carousel (New arrivals / Best sellers / Top accessories / a category / a collection / products you pick)
   - **Content**: Rich text, Image banner, Image with text, FAQ, Call to action (up to 3 buttons)
3. To **change** a section: click it to open, edit the text/images, done.
   - **Category grid**: pick which categories show and their order (empty = all main categories). The **first** category gets the big tile. Each tile's **icon**, and the big tile's **picture**, are set on the category itself: **Products → Categories** → open it → **Icon** / **Image** → Save.
4. To **add** a section: **Add Section** at the bottom → pick the type → fill it in.
5. To **move** a section: drag the handle (⋮⋮) on its left. To **remove**: ⋯ on the section → **Remove**.
6. Changes are saved as a **draft automatically** while you type. Shoppers **don't see them yet**.

## 2. Preview and publish

1. Click **Live preview** (top of the page) to see your draft beside the editor. Switch between **Mobile**, **Tablet** and **Desktop** sizes.
2. Or click **Preview** to open the draft in a new tab (only you can see it).
3. When happy, click **Publish changes**. The live site updates within a minute.
4. **Schedule**: next to Publish you can choose a date and time to publish later (e.g. a sale banner at midnight).
5. **Undo**: tab **Versions** → open an older version → **Restore**.

## 3. Other pages

1. **Online store → Home page & pages → Create new**.
2. Fill **Title**, the **Heading (H1)** (and optional highlighted part), and add **Sections** like the home page.
3. Set the **handle** – the page appears at `/pages/<handle>`.
4. Fill the **SEO** title and description. **Publish**.
5. Add a link to it in a menu (section 6).

## 4. Theme colours, logo and fonts

1. **Online store → Theme**.
2. **Logo & icons**: logo for dark and light mode, favicon, logo height.
3. **Colours**: background (dark and light), accent, gradient start / middle / end. Use hex codes (e.g. `#3B82F6`).
4. **Typography & buttons**: font (Inter, Space Grotesk, Montserrat, Poppins), button style, card corner roundness.
5. **Colour mode**: default dark or light, and whether visitors can switch.
6. **Save** – theme changes go live straight away (there's no draft), so make small changes and check the store each time.
7. **Changed your mind?** Tab **Versions** (top right) lists the last 30 saves of the Theme – open one and **Restore this version**; the store follows straight away. The same works for **Header**, **Footer**, **Announcement bar** and **WhatsApp button**.

## 5. Announcement bar (the strip at the very top)

1. **Online store → Announcement bar**.
2. Tick **enabled**, write the **text** (e.g. "Free delivery in Karachi above Rs 15,000"), optional **link** and **link label**, colours.
3. Optional **start** and **end** date/time – it shows only in that window.
4. Tick whether to show phone / WhatsApp / email on the right. **Save**.

## 6. Menus, header and footer

1. **Online store → Menus** → open a menu (or **Create new**).
2. Add items: **label** + **link** (e.g. `/category/laptops`, `/pages/about`). Add sub-items under an item for dropdowns. Tick **Show as mega menu (desktop)** for a big dropdown with icons/images.
3. Drag to reorder. **Save**.
4. **Online store → Header**: which menu is the **main menu** and which is the **mobile menu**; sticky header, search, language and account icons.
5. **Online store → Footer**: about text, up to 4 columns (title + menu), payment badges, copyright (`{year}` and `{store}` fill themselves in).

## 7. Policy pages (shipping, returns, privacy, terms, about, installments)

1. **Online store → Page texts**.
2. **Add Page** → choose the page in the **Page** list → write the **title**, **description** (for Google) and **body**.
3. The body uses simple formatting (Markdown): `## Heading`, `- bullet point`, `**bold**`, `[link text](/contact)`.
4. Set **Last updated** to today. **Save** – this goes live straight away.
5. Automatic parts you edit elsewhere:
   - **Shipping policy** shows your delivery zones from **Delivery & payments → Delivery charges**.
   - **Warranty & returns** shows the rules from **Settings → Returns & warranty rules**.

## 8. Other content

- **Online store → WhatsApp button**: the floating WhatsApp button – numbers, pre-filled message, position.
- **Online store → Testimonials** and **FAQs**: used by the Testimonials and FAQ sections.
- **Online store → Blog**: write posts; they have drafts and scheduling like pages.
- **Online store → Photos & files**: every uploaded photo.

## 9. Good habits

- Change one thing, preview it on **Mobile**, then publish.
- Keep headings short. Use real photos.
- Don't put prices in banner text – they go out of date. Link to the product instead.
- If something looks wrong after publishing, open **Versions** and restore the previous one.
